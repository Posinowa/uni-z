# Uni'z Mobile

Uni'z mobil uygulaması — Flutter ile geliştirilmiş Android ve iOS uygulaması.

## Gereksinimler

- Flutter SDK (3.10+)
- Android Studio / Xcode (platform geliştirme için)

## Kurulum

```bash
flutter pub get
```

## Çalıştırma

```bash
flutter run
```

## Proje Yapısı

Feature-based architecture kullanılmaktadır:

```
lib/
 ├── app/
 ├── core/
 ├── features/
 ├── shared/
 └── main.dart
```
